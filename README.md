# Python Project Portfolio

A collection of Python projects developed to practice programming fundamentals, game development, and desktop application development.

## Projects

### 1. Number Guessing Game
A number guessing game with difficulty levels, limited attempts, score calculation, and replay functionality.

**Concepts:** Variables, conditionals, loops, random numbers, exception handling.

**Run:**
```bash
py sayi_tahmin_oyunu.py
```

### 2. Mini Escape Game
A 2D arcade game built with Pygame. Move the player, avoid falling obstacles, collect points, and try to beat your high score.

**Features:** Keyboard controls, collision detection, lives, scoring, increasing difficulty, persistent high score.

**Requirement:** Python 3.13 and Pygame.

**Install and run:**
```bash
py -3.13 -m pip install pygame
py -3.13 kacis_oyunu.py
```

### 3. Smart Study and Task Tracker
A desktop application for managing study tasks, deadlines, priorities, and completion status.

**Features:** Task creation, search, status filtering, task deletion, and persistent JSON storage.

**Concepts:** Tkinter, functions, lists, dictionaries, file handling, JSON.

**Run:**
```bash
py -3.13 ders_takip.py
```

## Skills Practiced

- File handling and JSON
- Debugging and testing
